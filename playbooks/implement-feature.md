# Playbook: implement feature

1. Obtain/clarify expected behavior and non-goals.
2. Prepare the task context before broad exploration.
3. Check work admission before mutating code.
4. Work in an isolated engineering workspace.
5. Use fast/affected verification during iteration.
6. Run the required full verification before submitting.
7. Submit one coherent change with evidence.
8. Track PR -> CI -> merge -> required deploy verification.
