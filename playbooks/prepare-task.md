# Playbook: prepare task

Use this before broad repository exploration by an expensive coding model.

1. Call the transport-neutral `prepare_task` capability (CLI, library or MCP).
2. Prefer an index only when it is available and compatible with the target revision.
3. Fall back to raw-repository discovery automatically.
4. Give the Task Packet to the implementation/review agent.
5. Let the coding agent expand beyond the packet only when the packet is insufficient.

Do not require the index for correctness.
